1. Quick Start

1 Open the project
ArtGenerator/ArtGenerator.xcodeproj in Xcode 15 or later
2 Add your paid OpenAI API key
Open Configurations/AppConfig.swift and replace the placeholder: 
static let apiKey: String = "sk-proj-YOUR_KEY_HERE"
Get a key at platform.openai.com/api-keys after billing is enabled.
3 Replace placeholder URLs 
static let emailSupport = "support@yourdomain.com"
static let privacyURL = URL(string: "https://yourdomain.com/privacy")!
static let termsAndConditionsURL = URL(string: "https://yourdomain.com/terms")!
4 Configure StoreKit for testing
Product → Scheme → Edit Scheme → Run → Options → StoreKit Configuration → Products.storekit
5 Build and run
Select an iPhone simulator or a connected device → Cmd+R
Done. You should see the Muse AI splash, then onboarding. Generation still needs a paid OpenAI account with credits.

2. Beginner Xcode Guide

You can reskin Muse AI without being a senior iOS developer. Work in small steps and run the app after each change (Cmd+R).

2.1 Open and run

  1. Double-click ArtGenerator.xcodeproj.
  2. Wait until indexing finishes (progress in the top status bar).
  3. In the toolbar, choose iPhone 15 (or any simulator).
  4. Press the Play button or Cmd+R.

If signing fails, select the ArtGenerator target → Signing & Capabilities → check Automatically manage signing → pick your Apple ID team.

2.2 Change text you see on screen

  1. Press Cmd+Shift+F (Find in Project).
  2. Type the exact words from the UI, for example Meet Muse AI or Upgrade to Pro.
  3. Open the result. Text lives inside quotes, like Text("Meet Muse AI").
  4. Change only the words inside the quotes. Do not delete the quotes or parentheses.
  5. Run again to confirm.

Splash title and Settings version come from AppConfig.swift (appName, appTagline, appVersion). Change them once and several screens update together.

2.3 Change the app name on the home screen

  1. Click the blue ArtGenerator project icon in the left file list.
  2. Select the ArtGenerator target → General → Display Name.
  3. Type your name (keep it short; iOS truncates long names under the icon).
  4. Also set AppConfig.appName to the same string.

2.4 Change colors

All brand colors live in Configurations/DesignSystem.swift.

// Main brand color (buttons, chips, selected states)
static let accent = Color(hex: "E11D74")

// Lighter tint
static let accentLight = Color(hex: "F472B6")

Use a 6-digit hex without #. Examples: blue "2563EB", teal "0D9488", gold "D4A574".

Button fills use DS.Gradients.accent a few lines below. Change those hex values to match your accent so splash, paywall, and Generate stay consistent.

2.5 Change the app icon

  1. Prepare a 1024×1024 PNG (no transparency for App Store).
  2. In Xcode, open Assets.xcassets → AppIcon.
  3. Drag your PNG onto the 1024 slot, or replace app-icon.png in AppIcon.appiconset.

3. Onboarding and Paywall Walkthrough

3.1 First launch

  1. Splash — About 1.6 seconds. Shows the Muse AI name and tagline Imagine. Create. Share.
  2. Onboarding page 1 — Meet Muse AI.
  3. Onboarding page 2 — Twelve signature styles.
  4. Onboarding page 3 — Personal studio / gallery.
  5. Onboarding page 4 — Five free images daily. Start Creating dismisses onboarding. Skip is available on pages 1–3.

Onboarding is stored in UserDefaults under hasSeenOnboarding. To see it again, delete the app from the simulator or device and reinstall, or search that key in code and reset it while debugging.

3.2 Paywall

The paywall is Views/PaywallView.swift. It appears when:

  • The user taps Upgrade to Pro in Settings or the iPad sidebar.
  • The user hits a locked style or Pro-only feature.
  • The user finishes their 3rd generation (AppConfig.paywallAfterGenerations).

What you should see:

  1. Close button (top right).
  2. Headline from the A/B variant (yearly-first or lifetime-first).
  3. Rating / creations / styles badges.
  4. Free vs Pro comparison.
  5. Three products: Monthly $3.99, Yearly $9.99, Lifetime $19.99 (prices come from StoreKit when products load).
  6. Purchase button, Restore Purchases, Privacy Policy, Terms of Use.

Local testing: attach Products.storekit in the scheme. Purchases complete without a real charge. On a device without that file, use a Sandbox Apple ID.

4. Test on a Physical Device

The simulator is fine for UI. Use a real iPhone or iPad for haptics, the photo picker, widgets, notifications, and StoreKit sandbox.

  1. Plug in the device and unlock it. If macOS asks to Trust This Computer, confirm on the phone.
  2. In Xcode, set the run destination to your device (not a simulator).
  3. Target → Signing & Capabilities → Automatically manage signing → select your Team.
  4. If the bundle ID is already used, change it to something unique such as com.yourname.museai. Keep the widget extension bundle ID as your.main.id.ArtGeneratorWidget (or match whatever Xcode suggests).
  5. On the device go to Settings → General → VPN & Device Management (or Device Management) → tap your developer name → Trust.
  6. Confirm AppConfig.apiKey is a real key from a paid OpenAI account with credits. The device must be on Wi-Fi or cellular.
  7. Press Cmd+R. After install, walk through splash → onboarding → Explore → Create → Gallery → Settings → paywall.
  8. Subscriptions: either leave StoreKit Configuration set to Products.storekit while running from Xcode, or sign out of the real App Store on the device and sign in with a Sandbox tester from App Store Connect.
Free Apple ID vs paid Developer Program: You can install on your own iPhone with a free Apple ID for a few days. App Store submission, TestFlight, and longer device installs need the $99/year Apple Developer Program.

6. Architecture and Data Flow

Muse AI is SwiftUI only (no Storyboards except the launch screen). Pattern: MVVM-style views + one observable DataManager + focused service types.

6.1 Layers

LayerTypesRole
App entryArtGeneratorApp, AppDelegateWindow, DataManager, splash / onboarding gate
ConfigAppConfig, DesignSystemBrand, API key, limits, colors, type, spacing
UIFlows/* and Views/*Screens. They read/write DataManager; they do not call the API directly
StateDataManagerPrompt, selected style, generated image, premium flag, error alerts
ServicesOpenAIService, StoreKitManager, GalleryManager, othersNetwork, purchases, disk, streaks, notifications
ModelsArtStyle, AssetModel, GeneratedArtPlain data

6.2 Generate-image data flow

CreatorTabView (user taps Generate) │ ▼ DataManager.generate() │ checks remainingFreeGenerations / isPremium ▼ OpenAIService (Swift actor, thread-safe) │ POST {apiBaseURL}/images/generations │ Authorization: Bearer {AppConfig.apiKey} ▼ OpenAI API (buyer's paid account + credits) │ JSON with base64 image ▼ UIImage in DataManager.generatedImage │ ▼ GalleryManager.save() → Documents directory + metadata JSON │ ▼ GalleryView / ImageDetailView refresh via @Published

6.3 Subscription data flow

PaywallView / Settings │ ▼ StoreKitManager.purchase(product) │ StoreKit 2 Product.purchase() ▼ App Store / StoreKit Configuration file │ ▼ Transaction.currentEntitlements │ ▼ DataManager.isPremium == true │ ▼ Limits removed (styles, batch, upscale, daily cap)

Concurrency: OpenAIService is an actor. UI types that own @Published state are marked @MainActor.

9. OpenAI API Setup (Paid Account Required)

Required: a paid OpenAI API account and credits that you purchase yourself. A ChatGPT Plus login is not enough. You need API billing on platform.openai.com.

9.1 Create the account and key

  1. Go to platform.openai.com and sign up or log in.
  2. Open Settings → Billing → add a payment method.
  3. Buy credits (or enable usage-based billing) and set a monthly limit.
  4. API Keys → Create new secret key.
  5. Paste it into AppConfig.swift. Never commit a real key to a public repo.

9.2 Approximate costs

gpt-image-1Medium~$0.04

gpt-4o-mini (prompt enhance)—~$0.005

Prices change. Check OpenAI’s current pricing page.

9.3 Production security

The default project calls OpenAI from the device so setup stays simple. For a public App Store app, set useBackendProxy = true in AppConfig.swift and keep the real key on your server.

14. Troubleshooting

“Billing hard limit has been reached” / insufficient quota

Your OpenAI account needs credits. platform.openai.com → Billing → add credits. This is expected until a paid API account is funded.

“Invalid API key”

The key must start with sk- and must be pasted without extra spaces. A ChatGPT password will not work.

Haptic errors in the simulator console

Apple simulator noise. Ignore it. Test haptics on a device.

“No active account” StoreKit

Attach Products.storekit in the scheme, or use a Sandbox Apple ID on a device.

Widget missing

Run the main app once, then add Muse AI Inspiration from the widget gallery.
