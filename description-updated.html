What the App Does

Users type a description such as “a cat wearing a space suit on the moon.” Muse AI generates an image in about 10–30 seconds. They can pick from 12 styles, adjust quality and size, save to a gallery, edit with filters, upscale, and share. Free users get 5 images per day. Paid subscribers get unlimited access.

How to Test on a Physical Device

  1. Connect an iPhone or iPad with a Lightning/USB-C cable and unlock the device.
  2. In Xcode, open ArtGenerator.xcodeproj, select the ArtGenerator scheme, then pick your device in the run destination menu.
  3. Signing: Target → Signing & Capabilities → enable Automatically manage signing → choose your Team. Change the bundle ID if the default is taken (for example com.yourname.museai).
  4. On the device: Settings → General → VPN & Device Management → trust your developer certificate.
  5. Add your paid OpenAI API key in AppConfig.swift before running. Generation needs a network connection and API credits.
  6. For subscriptions on device, use a Sandbox Apple ID (App Store Connect → Users and Access → Sandbox) or keep Products.storekit selected in Edit Scheme → Run → Options while debugging from Xcode.
  7. Press Cmd+R. The splash, onboarding, create, gallery, and paywall flows all run on device. Haptics and the camera/photo picker work only on hardware, not the simulator.

Beginner Guide: Change Text and Colors in Xcode

You do not need to be an expert. These are the most common edits:

Change on-screen text

  1. Open the project in Xcode.
  2. Press Cmd+Shift+F to search the whole project.
  3. Search for the words you see on screen (for example “Meet Muse AI” or “Upgrade to Pro”).
  4. Click a result, edit the quoted text, then press Cmd+R to run.

Change the app name

  1. Select the ArtGenerator target → General → Display Name → type your name.
  2. Also change AppConfig.appName and AppConfig.appTagline in Configurations/AppConfig.swift. Splash, watermark, and Settings read from those values.

Change colors

  1. Open Configurations/DesignSystem.swift.
  2. Edit DS.Colors.accent (the rose brand color). Use a 6-digit hex such as "E11D74".
  3. Edit DS.Gradients.accent if you want the buttons and splash ring to match.
  4. Run the app. Buttons, selected chips, and highlights update together.

A longer step-by-step with architecture notes is in Documentation/index.html.

Architecture and Data Flow

The app uses SwiftUI with a single shared DataManager (ObservableObject) plus small service classes.

  1. The user types a prompt on CreatorTabView.
  2. DataManager checks the daily free limit, then calls OpenAIService (a Swift actor).
  3. OpenAIService sends HTTPS requests to the OpenAI API using your key from AppConfig.swift. Image bytes come back as base64 and become a UIImage.
  4. GalleryManager writes the image and metadata to disk. The Create screen and Gallery both observe this state and refresh.
  5. If the user is not subscribed, StoreKitManager loads products and PaywallView handles purchase / restore. Entitlement is stored with StoreKit 2.

There are no CocoaPods or Swift Package Manager dependencies. iOS 16.0+, Swift 5.9, Xcode 15+.

Setup (about 5 minutes)

  1. Open ArtGenerator.xcodeproj in Xcode 15 or later.
  2. Create a paid OpenAI API account, add credits, and paste the key into AppConfig.swift.

  5. Build and run on the simulator or a physical device.
